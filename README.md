# 数据采集工作台

一个面向**多账户批量数据采集**的桌面应用。填几个账户链接，点一下，自动登录、逐条采集、写入在线表格——全程本地运行，无需安装 Python 或浏览器插件。

> 安装包在 `exe/` 目录：**数据采集_setup_v2.4.1.exe**（39 MB）。双击安装即可，无需配置 Python / 浏览器环境。首次运行需在安装目录下新建 `config.json`（参考 `config.example.json` 填写账户链接与表格凭证）。

---

## 解决什么问题

运营团队每天要看几十个账户、上千条计划的消耗数据。手动一个个登录、翻页、抄数、填表，重复且易错。这个应用把整条链路自动化：

1. **多账户轮询** — 按顺序自动打开每个账户，复用登录态
2. **状态校验** — 检查页面四元素（投放模式、商品类型、下划线等）确认页面处于预期状态，不对就不采，避免抓错
3. **条件筛选** — 按日期范围、搜索词、计划状态、主播名筛选目标数据
4. **逐条采集** — 打开每条计划的素材抽屉，读取整体消耗与个人消耗
5. **自动写表** — 结果实时写入在线协作表格，无需手工搬运

单账户完整跑完约 30–60 秒，替代原来 10–20 分钟的人工操作。

## 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| 桌面 GUI | Python + PySide6 | 本地窗口，进度实时滚动 |
| 浏览器自动化 | Playwright | 驱动真实浏览器，复用持久化 profile |
| 登录态 | storage state | cookies + localStorage 存盘，跨次运行免登录 |
| 页面交互 | 注入 JS | 按表头文字定位列、多方案兜底点击"下一页" |
| 稳定性 | 状态校验 + 等待收敛 | 页面元素不对就停；DOM 稳定后才读，避免拿到旧数据 |
| 数据输出 | 在线文档 API | 采集结果直接写入协作表格 |
| 打包 | PyInstaller onedir | exe + 运行库，无需用户装环境 |

## 工程亮点

- **四元素状态校验**：采集前先检查页面关键元素的文字、颜色、下划线组合，全部符合预期才继续。页面改版或异常状态时主动停下，而不是抓一堆错数据。
- **登录态持久化**：不只保存浏览器 profile——会话 cookie 单独存盘并注入，解决"浏览器一关登录就没了"的问题。
- **表头对齐取数**：不写死"第几列是消耗"，按表头文字定位列号。表格加列、换列顺序都不影响。
- **下一页多方案兜底**：自定义分页组件不响应普通 click，准备了箭头定位、文字匹配、页码点击多种方案依次尝试。
- **并发保护**：文件锁防止两个进程用同一个 profile 互相破坏；崩溃残留的锁文件可自动清理。

## 运行说明

安装包已包含完整运行时：主程序 + `_internal/`（运行库）+ `ui/`（界面文件），开箱即用。首次运行需在安装目录下新建 `config.json`（参考 `config.example.json` 填写账户链接与表格凭证）。

## 配置说明

参考 `config.example.json`。首次运行会生成空配置，需要自行填写：
- 账户链接 / ID
- 采集参数（日期、搜索词、筛选条件）
- 在线表格凭证

**请勿把填好的 `config.json` 提交到任何公开仓库**——它含账户 ID 和文档访问 token。
